# Learning platform and technical help

The learning platform supports the current and previous major versions of Chrome, Firefox, Safari, and Edge. JavaScript and cookies must be enabled. Mobile browsers can read course material, but timed assessments should be completed on a laptop or desktop with a stable connection.

Uploaded assignments accept PDF files up to 25 MB. A submission is complete only when the platform displays a confirmation number. The assistant cannot inspect uploads, retrieve confirmation numbers, extend deadlines, or determine whether the platform is currently experiencing an outage.

If a page does not load, refresh once, sign out and back in, then try a supported browser. Students should retain the confirmation number and a local copy of submitted work. Published deadlines remain in effect unless the university issues a written extension.
